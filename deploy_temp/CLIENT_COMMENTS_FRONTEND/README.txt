FRONTEND ONLY - peachpuff-snail File Manager
===========================================
1) Open peachpuff-snail site File Manager
2) Go to public_html (or site root where index.html is)
3) Upload index.html (overwrite)
4) Upload entire static folder (overwrite existing)
5) Hard refresh client page Ctrl+Shift+R

Backend also required: upload client-comments-BACKEND.zip files to steelblue nodejs as per that README.
